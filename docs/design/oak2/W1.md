# Oak 2.0 — Wave W1 state

What W2–W4 can rely on after W1 (Studio core), and what W1 leaves open. The binding text is `docs/design/contracts.md` §13 (§13.5 "W1 state"), §10.7 (`[[later]]`) and §10.11 ("Judging a piece"); this page is the seam between the waves. Plan: `docs/oak2/PLAN.md` revision 2 (§2 fidelity rules bind every wave), §4 S1–S4 and S7; wave plan: `docs/superpowers/plans/2026-11-25-oak2-w1.md`. The previous seam is `W0.md`.

## 1. Studio code lines (`@oak/content-kit` `studio-code.ts`, re-exported by `@oak/api`)

Pure, isomorphic, no Strudel evaluation.

- `labelledLines(code): CodeLine[]` (`{ label, muted, from, to, text }`): every labelled top-level statement, in source order, muted ones (`_x`, `x_`) included. A statement starts at a line whose first non-space text is outside a string, template, comment or bracket; a line starting with `.`, or any line while a bracket is open, continues it. `$:` twice gives two lines.
- `lineAt(code, offset): CodeLine | null` (the line under the cursor).
- `constDecls(code): ConstDecl[]`; `scrapCode(code, label | CodeLine): string | null` = every const the line uses, transitively, in source order, then the line.
- `tempoLineOf(code)`, `chainLinks(expr)` (top-level `.name(args)` links, `null` for anything not a call chain), `SOUND_LINKS`, `soundSettingsOf(statement)` (the statement's sound links in written order).
- `STUDIO_ROLES` = `drums`, `bass`, `chords`, `tune`, `other` (equal to `SCRAP_ROLES`); `roleOfLabel(label)`.
- `PLAIN_SOUNDS` = `{ bass: "triangle", chords: "piano", tune: "sine" }`, Oak's call. **W2 swaps these for sound pack v5's `plainbass`, `plainkeys`, `plainlead` after its merge (one edit, its Task 14 Step 6).** `OAK_DEFAULTS.lines` and the plain start follow automatically.

## 2. Takes (`TAKE_STATES`, `sketches.patchVersion`)

- `TAKE_STATES` = `open`, `kept`, `cut`; `null` = not a take. No migration (no CHECK).
- A Run that saves while Jam is on writes a version with `takeState: "open"`. `sketches.create` takes no `takeState`, so a first version is never a take.
- `PATCH /api/sketches/:id/versions/:version { takeState }` (`LibraryService.patchSketchVersion`, mounted in `libraryRoutes`): 400 for a state outside `TAKE_STATES`, 404 for an unknown sketch or version, never deletes. Cut takes are hidden in the Takes panel ("Show cut takes"), "Bring back" sets `open`.
- `SketchVersion` now always carries `takeState`, `parentVersion`, `generation`, `dimension` (`null` when empty); `Sketch` always carries `committed` and `cards` (`[]` when empty). `SketchVersionCreate` accepts `parentVersion`, `generation`, `dimension` and stores them, so W3's siblings and generations (X15) need no repo change; `sketches.lineage` is still pending.
- `SketchPatch` accepts `committed` and `cards` (each replaces the whole list; `[]` is stored as NULL). W3's cards write `cards` through it.

## 3. Server services (each builds its repository from `ctx.repos.db`; a backup import rewrites the same `Db`)

| Service (`server/src/services/…`) | Route function (`server/src/routes/…`) | `Services` key | Endpoints |
|---|---|---|---|
| `ScrapsService` (`scraps.ts`; repo `db/repos/scraps.ts`; `indexScrapId`) | `scrapsRoutes(mount, scraps)` (`scraps.ts`) | `scraps` | `scraps.list`, `scraps.create`, `scraps.delete` |
| `UserTemplatesService` (`user-templates.ts`; repo `db/repos/user-templates.ts`; `templateOfCode` in `template-code.ts`) | `templatesRoutes(mount, templates)` (`templates.ts`) | `templates` | `templates.list`, `templates.create`, `templates.patch`, `templates.delete` |
| `LaterService` (`later.ts`, private `LaterRepo`) | `laterRoutes(mount, later)` (`later.ts`) | `later` | `later.list`, `later.create`, `later.patch` |
| `LibraryService.patchSketchVersion` | in `libraryRoutes` | `library` | `sketches.patchVersion` |

All four are mounted in `app.ts` before `oak2PendingRoutes`. `OAK2_PENDING` (`server/src/routes/oak2.ts`, now `OAK2_ENDPOINTS` minus a built set) holds `sketches.lineage`, `album.patchTrack`, `habits.get`, `catalogs.list`, `catalogs.create`, `capstones.checkHistory`. A wave that builds one adds it to `OAK2_BUILT` there; `server/src/routes/oak2-w1.test.ts` pins the list and must be updated with it.

- **Scraps.** Index scraps: every labelled line (muted included) of the current version of every unarchived sketch, computed per list, never stored; id `idx_<sketchId>_v<version>_<position>`; `code` = `scrapCode`; `reviewBeforeRun` when the version is flagged. Saved scraps: `scraps` rows; `sourceKind: "sketch"` needs `sourceRef` `sk_…@<version>`. Delete of an index id → 409.
- **Templates.** `templateOfCode` keeps the first tempo statement and, per labelled unmuted part, its head with string arguments replaced by `"~"` plus only `SOUND_LINKS` links; everything else is in `dropped`. A template plays no note. `fromSketch` reads that version; `isBlank: true` clears every other Blank in the same transaction; list = Blank first, then by name. A template made from a flagged version keeps `reviewBeforeRun` (`markForReview`, an addition to X7's brief).
- **Later.** `list()` = open items oldest first, then done items newest done first; `?done=0|1` filters. `done: true` keeps an existing `doneAt`. Text at most 500 characters (`LATER_TEXT_MAX`).

## 4. App registries and models

- **Editor slots** (`app/src/studio/editor-slots.ts`): `EDITOR_SLOTS` = `make-blank` (header, `MakeBlankButton`), `sound-tools` (toolbar, `SoundTools`), `commit-guard` (aside, `CommitGuard`). `SketchEditor` renders each slot in its place with `EditorSlotProps` (`sketch`, `version`, `liveCode`, `cursorLabel`, `jam`, `editor`, `applyCode` = the tutor's Apply path, one undoable change). Header and aside slots are not rendered while an imported version is under review. W3/W4 add a Studio tool by adding a slot here, not by editing `SketchEditor`.
- **Capture engines** (`app/src/capture/engines.ts`): `captureEngines()` returns `{ tapsToMini, humFromPcm }` (X5 `@oak/audio/tap-notation`, a new package subpath so the registry never loads the mic worklet; X8 `@oak/pitch`). Also exported from the package indexes: `tapsToMini`, `TapGrid`, `TapsToMiniOptions`, `TapsToMiniResult` (`@oak/audio`); `humFromPcm`, `HumFromPcmOptions`, `HUM_PCM_MAX_GAIN_DB` (`@oak/pitch`).
- **Capture anywhere**: `app/src/capture/store.ts` (`openCapture({ to: "scrap" | "sketch", mode? })`), `CaptureButton` and `CaptureHost` in the shell (shortcut Mod+Shift+K); hum, tap and voice memo all land in scraps first.
- **Descriptive copy**: `isDescriptive(text)` / `VERDICT_WORDS` (`app/src/studio/descriptive.ts`). Every new Studio string is checked with it in its task's test; W3's cards and habits mirror should do the same.
- **`OAK_DEFAULTS`** (`app/src/studio/model.ts`): `{ bpm: 90, meter: "4/4", key: C major, lines }`; `lines` is computed from `BLANK_CODE`, both Over a Band starts and every `START_LINES` value. W3's habits mirror (X16 `summarizeHabits(items, defaults)`) ignores these lines and reads tempo against `OAK_DEFAULTS.bpm` (a start's chosen tempo is not in `lines`). The built-in Blank (`BLANK_CODE`) writes a tempo line and a comment, no part.
- **Starts** (`app/src/studio/starts.ts`): `drumsAndBassCode`, `plainStartCode`, `fillItAllCode` (each part becomes a const and an `arrange` of N sections), `blankStartBody`, `templateStartBody`. A template or Blank to review is linted strictly before create and otherwise opens in the Review panel. Oak's `STARTER_SONGS` are shown as "Learning kits".
- **Jam, takes, focus** (`jam.ts`, `takes.ts`): `studioChrome({ jam })` gates hints, tips and compare; `JAM_TUTOR_NOTICE`; `roughPassLine(code)` (shown as "What's in this take": `VERDICT_WORDS` matches "pass"); `TIMEBOX_MINUTES` (Oak's call); `buildFromTakes(takes, picks)`; `focusMutes`. `TutorSubject.closedNotice` is shown by the closed tutor panel and by `ask` while the subject is closed.
- **Commit sounds** (`commit.ts`): `soundChanges`, `restoreSound` ("put it back"), `heardComment` (listen-through's `// heard (muffled): …`).
- **Later on Today**: `LaterList` (after the day's card and "Other ways today"; hidden before onboarding); `later-queries.ts`.

## 5. Strudel adapter (`@oak/strudel`, on the already-exported types)

- `EditorHandle.setPlainSounds(on)`, `plainSounds()`: a live `withHap` filter (`plainTracks`, after transpose, before the scope tap) gives learner bass, chords and tune haps the plain role sound and strips `PLAIN_STRIP` keys; drums, Band tracks and the code are untouched; `queryHaps` reads with it off.
- `EditorHandle.setLintFloor("info" | "error")`: at `"error"` the editor shows error findings only; evaluation and locked-code refusal are unchanged.
- `MasterBus.setListenThrough("muffled" | "small-speaker" | "quiet" | null)`, `listenThrough()`: a stage between `volume` and `ctx.destination`; the analyser and the record tap hang off `trim`, so it never reaches the meters or a recording.
- Both listening aids reset when the editor (SoundTools) unmounts.

## 6. Tutor

- `persona.ts` gains `## Judging a piece` (contracts §10.11) and the `[[later]]` line in the output format; the persona's `prefixVersion` changes.
- `[[later]]` (contracts §10.7): server `parseMarkup` keeps it once, only with `MarkupOptions.thread` of `chat`, `hint` or `explain`; the app parses it to `{ kind: "later" }` and offers "Park it for later" (`later.create`, `source: "tutor"`).

## 7. Known gaps (W1 leaves these open)

1. **Capstone commit after its sound session** (PLAN S7) — W4.
2. **"One part only today" card and the "With a card" start** (PLAN S4, S2) — W3 (cards).
3. **"From a form you mapped" start** (PLAN S2, §6 F7) — W4.
4. **No key estimation for hum and memo captures**: capture uses the learner's last key or C major (`DEFAULT_KEY`); `capture/model.ts` and `studio/model.ts` each define a C-major `DEFAULT_KEY`.
5. **Toolbox rows still say "Studio template"** (`content/toolbox.ts` is not touched in W1); Studio says "learning kit".
6. **`PLAIN_SOUNDS`** is `triangle`/`piano`/`sine` until W2 swaps in `plainbass`/`plainkeys`/`plainlead` after its merge.
7. **A template can fail to run when a kept tempo line or sound link names a const** (X7 supervisor probe): `const kit = "oak909"` + `.bank(kit)` gives `drums: s("~").bank(kit)` (ReferenceError); `const bpm = 96` + `setcpm(bpm/4)` likewise. `templateOfCode` drops every const. Not fixed in W1; a later wave either brings the referenced consts (they may hold notes) or inlines/drops such links.
8. **A drum rhythm's text can survive in a template**: `s("bd*4 sd").n("<0 1>")` keeps `s("bd*4 sd").n("~")` (plays nothing, but the habits mirror must not read template text as a habit). For X16.
9. **Saved scraps with a hand-edited `meter` or `key_json`** outside the enums make `scraps.list` answer 500 under response validation instead of skipping the row (X6 supervisor).
10. **Fill it all** takes bars from the source's stored length (`readLength ?? 4`); an idea longer than that length gets a `form.section-period` warning in the new sketch.
11. **Focus one part**: the read-only lines are not dimmed (the editable-range state draws nothing); the focused statement is outlined via `targetRegions`. Whether anonymous `$:` tracks are muted under the name `$` is not verified.
12. **`[[later]]` in a browser**: the fake tutor has no marker that answers with `[[later]]`, so `w1-later.pw.ts` covers the Today list only. `server/src/tutor/thread-view.ts` does not pass `thread` to `parseMarkup`, so server segments never carry `[[later]]` (the app parses the text itself, so nothing visible depends on it).
13. **Plain sounds in the roll and staff**: views reading `transport.haps` see the plain `s` while plain sounds are on; only `editor.queryHaps` is shielded.
14. **Real phone voice memos** (compression, AGC, room noise) were never tried; the X8 fixtures are synthetic. A voice within about 10 dB of the noise floor drafts nothing.
15. **Imported takes** are listed but not offered for "Build a version" or "Save line to scraps" (they would skip the strict lint).
