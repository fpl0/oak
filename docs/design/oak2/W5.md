## 4. The full suites (run once, 2026-11-25)

`bun run check:full` on the tree with the three fixers' changes. `check` stops on a red unit test, so its `e2e` half did not start (the allowed reds below); `bun run e2e` was then run once on its own.

- **Typecheck** (every project and package): exit 0.
- **Biome** (`biome ci .`, 2,948 files): no errors.
- **Unit** (`bun test --isolate`): 23,752 tests in 773 files, **23,740 pass, 4 fail**, 5 todo, 3 skip (1,836 s).
  - Allowed: `scripts/sounds/v5-lock.test.ts` "the lock is pack v5" (decision 114); the two `simulation.test.ts` companion assertions (decision 118).
  - `server/src/content/loader.test.ts` "the default order … as the generated course index has it": the gitignored `content/.generated/course-index.json` was built before W2 merged. The browser run's content build regenerated it, and the test passes alone (6 of 6). No code change.
- **Browser** (`bun run e2e`, 61 units, 61.6 min): 1,324 listed, **1,224 passed, 34 failed**, 5 skipped, 61 did not run (serial files behind a failure), 2 load-sensitive.
  - Every failure was a spec behind the code, none a W5 regression:
    - Seed points, orders and counts from before W2's 270-session course (the five new core lessons, GYM.01–GYM.18 moved, J3.L05, R1.L06, A2.L07–L09; the walk maps in `walk.ts`, `w5walk.ts`, `w6walk.ts` and `w7walk.ts` now match `content/syllabus.ts`): 29 failures. One of them is drift in what the seeded learner practised: "C2 released" leaves the cadence family at level 2, so the stage D card is put at its highest open level in the spec. Three more surfaced in tests that had not run (a U11 gym day is GYM.11, the last day's 269 sessions, and the jazz day's ii–V set no longer due on the J3.L02 day, which the spec now makes due).
    - Copy and behaviour that changed before 1.4.0 and that the specs never caught up with (the eval banner draws backticks as code, the ladder panel's "Level 1 · Drum loops", "Slower by 5%", the staff turning to a new loop region at once): 4 failures.
    - One real layout bug: a long lesson title in a Toolbox chip ("Learned in Sixteenths & 1-e-&-a") overflowed `/toolbox` by 21 px with the tutor docked at 1280 px (`contrast.pw.ts`).
  - The fixes (decision 144) were re-checked with `e2e:changed --files … --max 8` in 9 batches. Every failed test and every file with tests that did not run now passes; nothing was loosened.
  - **Flaky:**
    - `e2e/journey/w6-capstones.pw.ts` "(d) C6 session 2 as a day" (`ECONNRESET` beside other suites) passed alone in the full run and twice more alone (13 of 13 each). Load-sensitive.
    - `app/src/album/e2e/w7-review.pw.ts` "the whole course: … twenty distinct covers …" fails its first attempt even in a unit of its own: it reads 0 or 18 of the 20 covers right after both sides showed 12 and 8. It passed on the runner's retry alone in the full run and in two more runs, each failing first. Not loosened; it needs a look (a re-render of the album page between the two reads is the likely cause; W4 added `ShelfDrawer` to it).
  - **Unit, flaky:** `packages/grader/src/hosts/hosts.test.ts` "without the budget the same pattern needs the kill path" failed once in `test:changed` (the subprocess hit its 1 GB memory limit before the timeout: `crashed` instead of `timeout`). It passed alone twice (34 of 34) and in the full run.
